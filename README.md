# eWorker360 Dominicana — propuesta web

Abre `index.html` en un navegador para revisar la experiencia. La propuesta incluye selector ES/EN, navegación de audiencias, servicios, soluciones B2B, cultura, vacantes de demostración con búsqueda y filtros, formulario local, FAQ, metadatos sociales, robots y sitemap.

Las fotos de equipo usan enlaces públicos del sitio original. La nueva imagen del hero se generó específicamente para esta propuesta y reemplaza el retrato original solicitado.

Antes de publicar: conecta el formulario a CRM/correo, confirma WhatsApp, vacantes, salarios/beneficios y todas las métricas, y migra la arquitectura a la implementación Next.js prevista en la especificación.
